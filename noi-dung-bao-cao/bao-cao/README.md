# Nội dung báo cáo

Nội dung báo cáo này bao gồm các chương trình bày chi tiết về quá trình phân tích dữ liệu chia sẻ xe đạp, từ việc khám phá dữ liệu, trực quan hóa, đến mô hình hóa và đưa ra các khuyến nghị dựa trên kết quả phân tích.

## Tên chính thức đề tài

Phân tích và dự báo nhu cầu sử dụng dịch vụ chia sẻ xe đạp tại Seoul.
